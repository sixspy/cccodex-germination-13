# 发芽口径核算台

种子检验室按书面口径给批次出数。现行口径的分母是播种粒数减去霉粒数，分子是发芽粒数。旧口径把霉粒留在分母里。核算员可以按现行口径再出一版，旧版数字仍留在记录里。

## 技术栈

| 层 | 选型 |
|----|------|
| 接口 | Python Bottle + Waitress |
| 页面 | Svelte 4，无组件库 |
| 数据库 | PostgreSQL 16 |

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3423 |
| 接口 | http://localhost:8423 |
| PostgreSQL | localhost:54623（库名 `germination`） |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| admin | 123456 | 核算员，可按现行口径出数。登录页已填好 |

## 启动

```bash
docker compose up --build
```

健康检查：`GET http://localhost:8423/api/health`
